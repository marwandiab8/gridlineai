Hours keyword guide

Start each job with a keyword so your hours go to the right activity. Winter work (hoarding, tarps, heaters, snow) is tracked separately, so always use a winter keyword when it applies.

By text: hours, keyword, then where. Put a dash between jobs.

5h hoarding prep east side - 3h hoarding lift L3 windows - 1h housekeeping

In Site Logistics (best): Tasks → My hours → Log today's hours. For each job pick where you worked, the keyword and the hours, then Send to gridlineai.

On the web form: pick the activity. Its keyword is shown in [brackets].

Four rules

  1. One job per part. Split "general labour and unloading" into two parts with their own hours.
  2. Keyword first, then where: snow ramp, railing reinstate stair 2.
  3. Say what carpentry was for: hoarding prep or railing carpentry, never just "rough carpentry".
  4. Another day? Start with the date, no spaces: 2026-10-01 5h hoarding prep - 4h housekeeping

Easy to mix up

hoarding prep / hoarding install / hoarding lift
Prep is cutting and getting material ready. Install is putting it up from the floor or a ladder. Lift is putting it up from the scissor lift. A day with all three is three parts.
tarps / hoarding install
Tarps is loose tarps to hold heat. If you are building or fixing the hoarding frame, use a hoarding keyword.
railing install / railing reinstate
Install is new railing. Reinstate is putting back railing that was taken down, or re-securing it.
snow / snow pump
Snow is shovelling. Snow pump is pumping out water from melted snow or ice.

Not sure which one? Use the closest one and add a note. Your supervisor checks every day before anything is final.
