# Field User Guide

This guide is for site staff, labourers, foremen, and anyone mainly using the system by phone.

## 1. Main ways to use it

You can use the system by:

1. texting the Twilio number
2. sending photos by MMS
3. calling the number and leaving a recorded voice message

## 2. Daily reporting by text

Send short, direct updates.

Examples:

```text
daily log: formed east wall, crane delayed 45 minutes
safety icy stairs at north entrance
delay rebar truck late
punch broken tile at lobby
log delivery windows delivered to south gate
```

You can also use shorthand:

```text
safety no guardrail at roof edge
delay pump breakdown
inspection fire stop reviewed level 4
progress duct rough-in complete at west corridor
```

## 3. Photos

Send progress photos or issue photos by MMS.

Best practice:

- send clear photos
- send a short text with the photo
- mention the area, trade, or issue

Example:

```text
punch cracked tile at lobby entry
```

with the photo attached.

## 4. Voice messages

If typing is too slow, call the number and leave a voice update.

Use voice for:

- long daily updates
- quick hands-free reporting
- driving / field movement situations

The system can transcribe and save the voice note into the reporting workflow.

## 5. Labour hours

If you are a registered labourer, you can text your hours.

Examples:

```text
labour 8.0 framing cleanup
8 hours forming elevator pit
labour 4.5 demolition, 3.5 cleanup
```

You can also ask for totals:

```text
how many hours today
how many hours this week
how many hours this pay period
```

If you made a mistake, text a correction:

```text
I made a mistake, correct the hours to 9.5
```

## 6. Ask for reports or summaries

Examples:

```text
daily summary
daily report pdf
status
help
```

## 7. Switching project context

If you work across projects, set the project first.

Example:

```text
project docksteader
```

Then continue sending updates.

## 8. Best practice

- Keep messages short and factual.
- Send updates as the work happens.
- Send photos with a short caption.
- Use voice when the update is long.
- Correct mistakes quickly so the saved record stays clean.

## 9. If something does not work

- If your hours do not log, ask management to confirm you are registered as a labourer.
- If a project command fails, ask management to confirm your phone is assigned to the project.
- If the assistant does not understand a message, simplify it and resend.
