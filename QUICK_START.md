# Quick Start

Use this if you want the shortest path to operating `gridlineai`.

## 1. What it does

The system lets users:

- text site updates
- send photos by MMS
- call and leave voice messages
- log labour hours
- ask for reports

Management can use the dashboard to review messages, run the assistant, generate reports, manage labour, and work with lookahead schedules.

## 2. Fastest user workflow

Text the Twilio number with messages like:

```text
daily log: poured east wall, crane delayed 30 minutes
safety missing guardrail at roof edge
delay concrete truck late
punch broken tile at lobby
labour 8.0 framing cleanup
how many hours this week
daily report pdf
```

You can also:

- send photos by MMS
- call the number and leave a voice update

## 3. Fastest management workflow

Open the dashboard and use:

- `Assistant`: send or test assistant requests
- `Reports`: open generated reports
- `Labour`: manage labourers and labour reports
- `Lookahead`: upload lookahead files and generate lookahead reports
- `Voice`: review voice transcripts and recordings
- `Team`: manage approved phones and member access

## 4. Most useful commands

```text
help
status
project docksteader
daily summary
daily report pdf
update project notes: north stair closed until inspection
labour 8.0 framing cleanup
how many hours today
how many hours this pay period
start timer for concrete pour
stop timer
```

## 5. If something fails

- If access is denied, check `Team` and project assignment.
- If labour logging fails, confirm the labourer is registered and active.
- If lookahead queries fail, upload and parse a lookahead schedule first.
- If a report link fails, check the `Reports` page and debug text.
